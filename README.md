# Paws & Feathers

An offline-friendly animal identification game designed for children in Years 1–2.

## Play

Open `index.html` in a modern browser. No installation or build step is needed.

The game includes:

- 75 real photographs across dogs, cats, birds, fish, sharks, and whales
- Five-question learning trails with child-friendly clues
- Optional read-aloud support, automatic answer-name pronunciation, and gentle sound effects
- Two-choice hints, instant feedback, points, stars, and a saved best score
- An animal book with simple facts for learning before or after a quiz
- Responsive layouts for desktop, tablet, and mobile

The photographs are bundled locally, so the game works without downloading images while children play. Photo source links are included in the animal fact cards.

The expanded Australian bird facts link back to [Australia's Wonderful Birds](https://www.australiaswonderfulbirds.com.au/).

The expanded dog facts are paraphrased from breed profiles and standards published by [Dogs Australia](https://dogsaustralia.org.au/BrowseBreed/browse-a-breed/).

The expanded cat facts are adapted from Wikipedia's [List of cat breeds](https://en.wikipedia.org/wiki/List_of_cat_breeds) and individual breed pages.
